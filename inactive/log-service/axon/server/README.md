# 项目简介

本项目是一个基于微服务架构的日志处理服务端系统

# 日志接收信息格式规范

## 日志数据结构

日志数据采用 JSON 格式进行封装，每个日志条目是一个独立的 JSON 对象，包含以下字段：

| 字段名称    | 数据类型      | 是否必填 | 描述                                                           |
| :---------- | :------------ | :------- | :------------------------------------------------------------- |
| `timestamp` | String        | 是       | 13 位毫秒戳                                                    |
| `level`     | String        | 是       | 日志级别，可选值包括 `DEBUG`、`INFO`、`WARN`、`ERROR`、`FATAL` |
| `message`   | String        | 是       | 日志的具体内容描述                                             |
| `source`    | String        | 是       | 日志来源标识，可以是服务名称或项目名称                         |
| `tags`      | Array[String] | 是       | 一组自定义标签，用于对日志进行分类和标记                       |

模拟数据如下：

```json
{
  "timestamp": "1744898364466",
  "level": "INFO",
  "message": "初始化README.md",
  "source": "jjq",
  "tags": ["init", "demo"]
}
```
