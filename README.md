## 📖 Project Overview

Originally developed as my personal website, this project has evolved into a **technology experimentation platform**. Whenever I want to test new architectural concepts or technologies, this is my primary testing ground.

> **Note**: Due to over-engineering concerns, my actual personal website has been migrated to [home-lite](https://github.com/Jjqcoder/home-lite).

## 🎯 Features

- Technology experimentation sandbox
- Continuous integration of new tech concepts
- Open for community contributions
